# NeonPocketMC-RC52 1.1 RC3

Experimental RC52 BLE companion release with a universal triple-press Home shortcut.

## Included files

- `NeonPocketMC-RC52-1.1-RC3.uf2` — normal application-only install through the RC52 UF2 bootloader.
- `NeonPocketMC-RC52-1.1-RC3.hex` — application image for advanced recovery/debug use.
- `SHA256SUMS.txt` — hashes for every attached payload.
- `NeonPocketMC-RC52-1.1-RC3-source-and-licenses.zip` — exact source and retained license notices.

Do not erase or replace the RC52 SoftDevice or bootloader. Do not flash these files to RCC6, RC32, or an RC52 with different display/radio hardware.

## Change since RC2

- Triple press returns directly to Home from any page.
- Triple press while reading Inbox clears every local unread message, then returns Home.
- A wake-only gesture remains consumed while the display is off.

## Qualification boundary

The functional firmware code at exact commit `120c4292d71b60790ef69c507c3053caf3481dc4` passed the RC52 exact-target build, UF2 checks, and T114 nRF52 regression in GitHub Actions run `31579818303`. The application-only candidate was also flashed and booted on the connected RC52 qualification unit. The release documentation commit changes no firmware inputs.
