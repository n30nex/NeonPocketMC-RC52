# NeonPocketMC-RC52 1.1 RC1

Experimental RC52 BLE companion release with the shared animated NeonPocketMC startup.

## Included files

- `NeonPocketMC-RC52-1.1-RC1.uf2` — normal application-only install through the RC52 UF2 bootloader.
- `NeonPocketMC-RC52-1.1-RC1.hex` — application image for advanced recovery/debug use.
- `SHA256SUMS` — hashes for the attached release files.
- `NeonPocketMC-RC52-1.1-RC1-source-licenses.zip` — exact source and retained license notices.

Do not erase or replace the RC52 SoftDevice or bootloader. Do not flash this image to RCC6, RC32, or an RC52 with different display/radio hardware.

## Changes since 1.0 RC1

- Animated NeonPocketMC startup mark and progress sequence.
- Canonical NeonPocketMC branding in the repository.
- Removed the inherited upstream Pages workflow that published unrelated MeshCore documentation.

## Qualification boundary

The exact tag is built by GitHub Actions with UF2 verification, upstream unit tests, and an existing nRF52 companion regression build. The RC52 hardware port was physically accepted in 1.0 RC1; this branding/startup update was not physically re-flashed because the RC52 unit was not connected.
