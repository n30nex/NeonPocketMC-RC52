# NeonPocketMC-RC52 v1.0.0-rc.1

The first experimental NeonPocketMC release for the Heltec RadioCore RC52-L62 with the vendor 220 x 128 NV3001B TFT.

> **RC52 only—do not flash RCC6, RC32, or RC52 variants with different display/radio hardware.**

![NeonPocketMC Home dashboard](https://raw.githubusercontent.com/n30nex/NeonPocketMC-RC52/main/docs/images/neonpocket-rc52-home.jpg)

## Included

- MeshCore 1.17 BLE companion firmware
- Native dark 220 x 128 NeonPocket dashboard and inbox
- Home, Inbox, Nearby, Radio, Bluetooth, Advert, and Power pages
- Local direct and channel unread tracking
- 60-second TFT timeout while BLE and LoRa remain active
- Application-only UF2 that preserves the RC52 bootloader and SoftDevice

## Provenance

- Firmware source: `14b949436d3e9c6200c3384d1963ec39fe2c637d`
- GitHub Actions run: https://github.com/n30nex/NeonPocketMC-RC52/actions/runs/31321748756
- The attached UF2 is byte-for-byte the firmware run on the qualification unit.

The owner confirmed the TFT UI, button behavior, BLE companion operation, and LoRa operation and authorized this RC1 release. Extended endurance testing and physical battery-ADC calibration are deferred.

## Flashing

1. Attach a suitable 868/915 MHz antenna.
2. Download the RC1 `.uf2` and `SHA256SUMS` assets.
3. Verify the UF2 checksum.
4. Enter the RC52 UF2 bootloader and confirm the mounted volume identifies an RC52/nRF52840.
5. Copy only the application `.uf2` to the UF2 volume.

Do not erase flash or replace the bootloader or SoftDevice. See the attached `FLASHING.md` for the complete procedure.

## Known limitations

- Experimental RC1; report issues with the exact asset filename and RC52 hardware revision.
- Battery ADC multiplier remains provisional.
- Low battery produces a warning only; there is no automatic low-voltage shutdown.
- This image supports BLE companion mode only; Web/AP, USB companion, and headless modes are intentionally excluded.
